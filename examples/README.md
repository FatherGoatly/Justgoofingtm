# Example macros

Reference solutions for the capstone of every tier, extracted from the curriculum by `node tools/build-examples.mjs`. Each file is the exact code the automated curriculum tests execute (in the sandbox or the Foundry emulator) before a release, so what you read here has been run. Headers state the runtime the example was tested in, the practice fixture it expects, and the Foundry/system versions it was written against.

| `10-expert-config-service.js` | Expert | t9-capstone | preview (practice) |

The sandbox examples run in any JavaScript engine; the emulator examples need Foundry globals and are meant to be pasted into the Academy workshop or a script macro.
